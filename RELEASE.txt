AIProxyOauth 2.0.0 release notes and gate
=========================================

2.0.0 is an intentional breaking CLI and configuration release. It introduces explicit
client-protocol versus upstream-provider terminology, the `serve`, `auth`, `key`,
`config`, and `doctor` command tree, strict explicitly selected YAML configuration,
provider-specific options, secret-only file/environment client authentication, three
startup-check modes, and one redacted startup renderer.

Release gate:

1. `mvn test`
2. `mvn clean package`
3. `java -jar target/AIProxyOauth-2.0.0.jar --help`
4. Complete `MANUAL_TEST_PLAN.md` on Windows and one Unix-like environment.
5. Confirm `startup.check: off` sends no inference requests.
6. Confirm dual-provider inference checks use `/v1/chat/completions` and `/v1/messages`.
7. Confirm serve failures are nonfatal and `doctor --inference` failures are nonzero.
8. Confirm output and protected request logs contain no OAuth tokens, proxy keys, or PII.

Tag only after the gate passes:

  git tag v2.0.0
  git push origin v2.0.0
