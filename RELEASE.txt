AIProxyOauth 3.0.0
=================

Adds GitHub Copilot as a direct HTTP provider alongside Codex and Anthropic.
Includes device login/logout, explicit file/environment credentials, account model
discovery, capability validation, both OpenAI client APIs, streaming, tools, usage,
and bounded client/account-isolated Responses replay.

Migration:
- auto includes credentialed Copilot; default order is copilot,codex,anthropic.
- both still means codex,anthropic; all requires all three providers.
- --provider-order ranks providers without enabling them.
- --default-provider must be enabled and takes precedence when eligible.
- --failover is opt-in, exact-model only, and stops before committed responses.
- Copilot model IDs are listed as copilot/<raw-id>.
- Startup always lists every known model, grouped in configured provider order.
- /v1/messages remains Anthropic-only.

GitHub.com device login and the Chat upstream protocol are live-validated. Both
OpenAI client APIs passed live streaming, synchronous, tools, and replay checks.
The Responses and Messages upstream protocols are offline-tested across both
client APIs. Broader live account/model coverage remains to be recorded.

GitHub Enterprise Cloud support is live-unverified. Per user instruction,
enterprise validation is optional and is not an implementation or release gate.
Offline host isolation remains required. GitHub Enterprise Server is unsupported.

Verification commands:
  mvn clean package
  python -m unittest scripts/test_copilot_contract.py scripts/test_live_compatibility.py
  java -jar target/AIProxyOauth-3.0.0.jar --version
  python scripts/live-compatibility.py --provider copilot --model <discovered-id>

Run packaged artifact checks on Windows and Linux. See MANUAL_TEST_PLAN.md for
remaining account-specific checks. This workspace prepares the release; it does
not create a tag, push commits, or publish an artifact.
