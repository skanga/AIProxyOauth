AIProxyOauth 3.0.2
==================

Patch release. Fixes the default GitHub Copilot OAuth app so new logins get
the full model catalog. No wire-format changes.

Copilot default OAuth app:
- `copilot.oauth_client_id` now defaults to `Iv1.b507a08c87ecfe98` (the
  ecosystem-standard Copilot device-flow app), which exposes the full Copilot
  model catalog. The previous default (`01ab8ac9400c4e429b23`) minted tokens
  under a restrictive integrator that only allowed a handful of models and
  failed the Copilot startup inference check.
- GitHub ties Copilot model access to the token's OAuth app ("integrator");
  see README. Existing tokens keep working until the next `auth copilot login`;
  re-login to adopt the new default. Override with
  `AIPROXY_COPILOT_OAUTH_CLIENT_ID` / `copilot.oauth_client_id` as before.

Verification commands:
  mvn clean package
  java -jar target/AIProxyOauth-3.0.2.jar --version
  java -jar target/AIProxyOauth-3.0.2.jar auth copilot logout
  java -jar target/AIProxyOauth-3.0.2.jar auth copilot login
  java -jar target/AIProxyOauth-3.0.2.jar serve --provider copilot

Confirm the Copilot startup banner lists the full model catalog and reports
Check: OK. See MANUAL_TEST_PLAN.md for remaining account-specific checks.
